# drogueriaSSF — Sistema de Gestión e Información para Droguería Rural

Proyecto formativo desarrollado en el programa **Tecnólogo en Análisis y Desarrollo de Software (ADSO)** del Servicio Nacional de Aprendizaje (**SENA** — Regional Distrito Capital, Centro de Electricidad, Electrónica y Telecomunicaciones - **CEET**, Ficha **3336091**).

## Descripción del Proyecto
Aplicación web orientada a optimizar la gestión operativa de una droguería rural mediante el control de inventario, seguimiento de lotes y fechas de vencimiento **INVIMA**, y administración de usuarios.

## Estructura del Repositorio
* `EV_01_fundamentos/`: Estructura base HTML5, estilos CSS iniciales e imágenes.
* `EV_02_Componentes/`: Modularización de componentes reutilizables (`header`, `card-producto`, `formulario-registro`), variables CSS y lógica JavaScript.
* `EV_03_Diseno_Frontend/`: Integración visual y maquetación responsiva del módulo *front-end*.

## Stack Tecnológico y Estándares de Codificación
* **Front-end:** HTML5 semántico, CSS3 modular y JavaScript (ES6+).
* **Base de datos:** Modelo relacional diseñado en MySQL.
* **Control de versiones:** Git (entorno local) y GitHub (repositorio remoto).
* **Convenciones de código:** `camelCase` (variables/funciones), `PascalCase` (clases), `UPPER_SNAKE_CASE` (constantes) y `kebab-case` (archivos y selectores CSS).
